## Quick Install (Direct Release — No App Store Required)

### 1. Android TV / Google TV / Amazon Fire TV Stick (`site.transdub.tv`)
1. Open **Google Play Store** or **Amazon Appstore** on your TV and install the free **Downloader** app (orange icon).
2. Enter Downloader short code:
   ```text
   6679937
   ```
   *(Or type `https://transdub.site/tv.apk`, or download `TransDub_TV.apk` from [Releases](../../releases/latest)).*
3. Install, open **TransDub TV**, and scan the on-screen QR code with your phone to sync your Watchlist & cast videos instantly.

### 2. Android Mobile (`site.transdub.browser`)
- Download `TransDub_Android.apk` from **[Latest GitHub Releases](../../releases/latest)** or **[https://transdub.site/download/android-apk](https://transdub.site/download/android-apk)**.
- Supports **Obtainium** for automatic GitHub Release updates.

### 3. iPhone / iPad (iOS)
- No App Store install required: open Safari -> **[https://transdub.site/m](https://transdub.site/m)** -> tap **Share → Add to Home Screen**.
- Pair with **TransDub TV** (`6679937`) via QR to bookmark shows and cast straight from iPhone to your TV.

### 4. PC Browser Extension (Chrome / Edge / Brave)
1. Download and unzip `TransDub_PC_Extension.zip` from **[Releases](../../releases/latest)** or **[https://transdub.site/download/extension](https://transdub.site/download/extension)**.
2. Open `chrome://extensions` (or `edge://extensions`) -> enable **Developer mode**.
3. Click **Load unpacked** and select the extracted folder.
4. Click the extension icon on any video page to save it to your Cloud Watchlist or toggle **LT AI** subtitles.
